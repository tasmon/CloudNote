## Notes for CloudPhone

A simple, fast notes app for CloudPhone feature phones. Create, edit, and delete notes,
with built-in backup and restore so you never lose what you've written.

### Features

- Create, edit, and delete notes
- Notes list sortable by newest, oldest, or title
- Adjustable text size (Normal / Large)
- Backup notes to a `.json` file
- Restore notes by choosing a previously saved backup file
- Full Left/Center/Right softkey support (Menu / Select / Back)
- Custom Settings, Help, and About pages


## Add to CloudPhone
1. Go to [CloudPhone Developer Page](https://www.cloudfone.com/my).  
2. Select **Add Widget**.  
3. Paste this Start URL:  
   `https://tasmon.github.io/CloudNote`  
4. Upload icons if required.  
5. Save and refresh - **CloudNote** will appear on your CloudPhone.
