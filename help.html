Help
Notes list
  • Up / Down: move between notes
  • Center key: open the selected note
  • Left key (Menu): New Note, Settings, Backup & Restore, Help, About
  • Right key: exit the app
Editing a note
  • Left key (Menu): Save, Delete Note, Cancel
  • Center key: quick Save
  • Right key: go back (asks to discard unsaved changes)
Backup & Restore
  • Backup: saves all your notes to a backup file
  • Restore: choose a saved backup file to bring your notes back
